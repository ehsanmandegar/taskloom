# Taskloom

Taskloom یک داشبورد محلی FastAPI + React است که اجرای تسک‌های مهندسی با Codex را از ثبت درخواست تا آماده‌شدن یک درخواست ادغام قابل بازبینی مدیریت می‌کند. هدف آن خودکارکردن اجرای Codex است، در حالی که تصمیم نهایی برای commit، push و ایجاد درخواست ادغام در اختیار کاربر باقی بماند.

## چه کاری انجام می‌دهد؟

1. مسیر repository، شناسه تسک، درخواست، راهنماها و دستور اختیاری تست را از یک فرم دریافت می‌کند.
2. تمیزبودن repository را بررسی می‌کند و برنچ `task/<task-id>` را می‌سازد.
3. Codex CLI را با sandbox محدود به workspace و همراه با راهنماهای انتخاب‌شده اجرا می‌کند.
4. تست‌ها را به‌صورت خودکار یا با دستور واردشده اجرا می‌کند و diff، فایل‌های تغییرکرده، خلاصه و خروجی تست را نشان می‌دهد.
5. فقط پس از موفقیت تست‌ها، commit دستی را فعال می‌کند؛ push نیز تا پس از commit و ایجاد Merge Request تا پس از push غیرفعال می‌ماند.

پروفایل‌های پروژه از بالای فرم قابل ذخیره و بازیابی‌اند و به‌طور پیش‌فرض در `~/.taskloom/profiles.json` نگهداری می‌شوند. برای تغییر محل فایل، متغیر محیطی `TASKLOOM_PROFILES_PATH` را تنظیم کنید. در بخش راهنما می‌توانید علاوه بر فایل، مسیر پوشه وارد کنید؛ همه فایل‌های `.md` آن پوشه و زیرپوشه‌هایش به‌صورت خودکار استفاده می‌شوند.

## راه‌اندازی

پیش‌نیازها: Python 3.10+، Node.js 18+، Git و Codex CLI که قبلاً login شده باشد. برای ایجاد درخواست ادغام، متناسب با سرویس remote باید GitHub CLI (`gh`) یا GitLab CLI (`glab`) نیز نصب و وارد حساب شده باشد.

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
Set-Location frontend
npm.cmd install
npm.cmd run build
Set-Location ..
.venv\Scripts\uvicorn main:app --reload
```

نسخه build شده روی `http://localhost:8000` در دسترس است. برای توسعه UI، در ترمینال دوم `Set-Location frontend; npm.cmd run dev` را اجرا کنید؛ Vite درخواست‌های `/api` را به FastAPI می‌فرستد.

> این ابزار برای اجرای محلی و کاربر مورد اعتماد طراحی شده است؛ آن را بدون احراز هویت روی اینترنت منتشر نکنید.

## دسترسی به راهنماها با MCP

یک MCP server فقط‌خواندنی در پروژه وجود دارد که فایل‌های Markdown را به‌صورت resource و با سه ابزار `list_guides`، `read_guide` و `search_guides` ارائه می‌کند. فایل `mcp-config.example.toml` نمونه تنظیم پروژه‌ای برای Codex است؛ جدول آن را در `.codex/config.toml` یک repository مورد اعتماد قرار دهید، Codex را از ریشه پروژه باز کنید و کلاینت را restart کنید. سپس با `/mcp` اتصال `taskloom_guides` را بررسی کنید.

برای اجرای مستقیم یا استفاده در یک MCP client دیگر:

```powershell
python -m backend.app.guide_mcp --root .
```

گزینه `--root` می‌تواند مسیر یک فایل Markdown یا پوشه باشد و برای چند مسیر قابل تکرار است. سرور فقط فایل‌های `.md` کشف‌شده در همین ریشه‌ها را می‌خواند و به فایل‌های بیرون از آن‌ها دسترسی نمی‌دهد.
